# Receipt expense extension

Mode: Operate. Extend the existing Daybook event detail and native sheet editors.
User request: scan a receipt, extract details with the on-device model, review/edit,
save with its photo attached to the event; expose an Action Button-compatible intent.

Use the existing warm Daybook forms, native navigation and toolbar actions, Dynamic
Type and semantic colors. Keep the receipt above labelled editable fields. Always
show processing, extraction failure/manual fallback and saved-draft states honestly.
A confirmed save requires merchant, civil date, positive total and supported currency.
No new visual identity, no browser or computer-control tools, no generated imagery.
Synthetic receipt fixtures verify layout and review behavior, not model accuracy.
