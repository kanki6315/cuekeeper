Cuekeeper is a native daybook for broadcast freelancers. No Cuekeeper login or demo account is required. Core local event, session and financial entry can be reviewed without connecting Calendar or iCloud.

Suggested walkthrough:
1. Complete first-launch preferences and choose Not now for Calendar.
2. Add an event with a name and dates. Add a client and a session, then edit their details.
3. Record a fee and use Payments to track invoices and payments. This is recordkeeping only: no banking, document sending, tax calculations or currency conversion.
4. In the event's Expenses, scan or import a one-page receipt, review the fields and save. Automatic extraction uses Vision and on-device Foundation Models. If the recognized text exceeds the on-device context limit, that text (not the photo) is retried once with Apple Private Cloud Compute; the expense screen discloses this before scanning and the completion message says when it was used. It requires Apple Intelligence availability; manual entry is available otherwise. No third-party or developer-operated AI endpoint is used.
5. Settings contains Calendar connection, Wallet Automation instructions, backups, Recently Deleted, support and privacy links.

Optional integrations:
- iCloud sync and manual backups use the signed-in user's private CloudKit database. The developer cannot supply a shared demo iCloud account containing user data. A fresh review installation may have an empty daybook.
- Calendar access is requested only when connecting. A single designated device publishes event placeholders and eligible confirmed, covering sessions. Open the publishing device with connectivity for reconciliation.
- Scan Receipt is a foreground App Shortcut and can be assigned to the Action Button on supported hardware. Capture Expense is a separate background intent that saves a draft; optional Wallet personal automation must be configured by the user in Shortcuts. Cuekeeper does not independently access Wallet transactions.
- Expense-completion notifications are optional local notifications with generic text.
- Home/Lock Screen widgets read the main app's schedule snapshot. They do not independently sync CloudKit; open the app to refresh the snapshot. OS scheduling controls widget reloads.
- Selected-venue maps and weather use Apple's services, not device GPS permission.
